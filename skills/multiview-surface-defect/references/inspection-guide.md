# 逐图检查与多视角核验

## 1. 输入与执行能力

以输入目录的一级子目录为物体 ID，目录内每张支持的图片为视角。枚举完整视角清单，排除隐藏目录和 `._` 辅助文件。图片不可读、无图片或路径缺失时记录具体问题，不用文件名推测内容。

使用宿主 Agent 的图片查看能力。若无法查看原图或细节，说明限制；不能仅凭文件读取成功就把视角写入 `views_inspected`。按物体分批输出，避免遗漏，并保留批次之间的对象清单。

## 2. 检查深度

按顺序进行：

1. **整体定位**：看清物体轮廓、朝向与可见表面。
2. **逐图表面检查**：查看原图或保留有效细节的物体区域；寻找窄长痕迹、边缘中断与局部材料缺口。
3. **候选细节复核**：对候选与模糊区域放大，检查是否有稳定的形态证据。
4. **跨视角核验**：判断同一表面区域是否在其他照片可见并有对应特征。

联系表适合导航，不适合排除细微缺陷。如果只完成初筛，在 `evaluation.md` 明确范围；检查不完整而不能可靠作阴性判断的对象使用 `review`。

## 3. 两类候选与混淆项

| 类别 | 可接受的可见证据 | 重点排除 |
|---|---|---|
| `linear_mark` | 不规则细长划痕、表面擦伤带、可见沟状痕迹 | 模具接缝、规律纹理、印刷线、细长反光、污渍 |
| `material_loss` | 边缘局部崩缺、断裂断面、缺失片块、不连续缺口 | 正常孔洞、锯齿、装配结构、遮挡与背景 |

没有形貌或稳定位置证据时，不用“有一条亮线”直接证明沟槽，不用阴影直接证明缺失。材质、成因、深度与严重程度无法由图片支持时不做确定推断。

## 4. 定位与计数

以最清晰的视角为 `evidence_view`，用原始图片坐标输出近似框 `[x1,y1,x2,y2]`。图像宽高为 `W,H` 时，像素位置映射为 `x/W*1000` 和 `y/H*1000`；裁剪图中的坐标先加上裁剪偏移，再映射到原图。

框应包住可见候选区域，不把整个物体框当作每条划痕的定位。多个无法可靠分离的细痕可记为一个区域簇，在 `uncertainty` 中注明“区域簇，未逐条分割”。汇总数是输出候选条目数，不是密集区域中的真实划痕条数。

比较物体朝向、结构锚点、区域位置与痕迹形状后再合并同一候选。不同物体即使外形相同也不能互作证据。无法判断两视角是否为同一处时保留不确定性，不能强行去重或重复计数后声称精确缺陷数量。

## 5. 跨视角关系

- `confirms`：其他视角的对应表面可见相符特征，记录具体位置或形态依据。
- `contradicts`：对应区域清楚可见且提供相反证据，例如所谓缺口实际是反光或遮挡。
- `not_visible`：背面、遮挡、视角或分辨率导致无法核验，不代表阴性。

同一原图裁剪放大不能算另一视角的独立佐证。不要为每个视角复制一句“相似线痕”并全部视为确认。

单视角形态证据清楚时也可报告；缺少其他视角确认不是剔除候选的理由。圆管等物体旋转后缺少可辨认锚点时，不能仅凭同类线痕强行建立实体对应关系。具体记录方式与双类别检查见 [evidence-workflow.md](evidence-workflow.md)。

## 6. 置信度与复核

`high`：目标形态清楚；`medium`：有合理视觉证据，但部分模糊、低对比或定位粗略；`low`：与正常结构或成像伪影难以区分。置信等级不是校准概率。

低置信、明显证据矛盾、重要区域不可见或检查未完成时，使用对象状态 `review`，填写 `review_reason`；低置信候选同时填 `uncertainty`。即使已有一个明确候选，对象的整体检查仍可能需要复核。
