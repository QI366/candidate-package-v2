# 执行评估与量化优化

## 无独立真值时

报告以下过程指标并列出原始分子、分母：

| 指标 | 计算方式 | 解释边界 |
|---|---|---|
| 文件读取覆盖 | 成功解码图片数 / 输入图片数 | 不代表已被模型查看 |
| 视觉初筛覆盖 | 被模型视觉初筛图片数 / 输入图片数 | 联系表不能排除细微缺陷 |
| 细节复核覆盖 | 已进行有效细节查看的图片数 / 输入图片数 | 说明原图、裁剪及分辨率 |
| 候选跨视角佐证比例 | 至少一个其他视角 confirms 的候选数 / 总候选数 | 不代表候选正确率 |
| 对象复核比例 | review 对象数 / 总对象数 | 不代表漏检率 |

没有候选时跨视角佐证比例记为 `null` 并说明分母为零，不写成 100%。如果仅按对象统计佐证，必须写“候选对象佐证比例”，不能和候选条目数混用。

脚本输出的 `declared_view_inspection_coverage` 是根据结果列表计算的自报覆盖。实际读取和检查深度必须有执行记录支持。Agent 的视觉判断属于模型推断，不能写成独立人工标注或人工复核。

## 有独立真值时

1. 由独立标注者标记目标类别、可见视角、框或多边形及对象级阴性。记录争议处理规则和标注版本。
2. 按物体分调参集与验收集；同一物体不同视角不能跨集合。相同来源或近重复样本也需避免泄漏。
3. 固定计数单位：物理候选或区域簇。真值逐条而预测成簇时，先统一粒度，不能直接宣称 F1。
4. 视图框评估在相同图片中做同类别一对一匹配；可报告 IoU≥0.30 与 IoU≥0.50 两套结果。物理候选级评估还需稳定真值实体 ID，跨视角匹配后去重。提前声明主指标、坐标标准和匹配方法。
5. 分类别报告 TP/FP/FN、precision=TP/(TP+FP)、recall=TP/(TP+FN)、F1=2TP/(2TP+FP+FN)。零分母记 `null` 并解释。
6. 补充阴性对象误报率、阳性对象漏检率、复核比例和耗时。明确 review 如何计入指标；同时报告自动结论的覆盖比例，不能通过大量弃权夸大性能。

## 可复现优化流程

先保存 baseline 的提示词、模型/Agent 可获得的标识、输入清单、输出和执行记录；拿不到精确模型名时写明未知，不能猜测。每轮优先改变一个因素，例如“联系表初筛”改为“逐视图物体裁剪+候选原图复核”。固定数据和评估规则后复跑，比较过程指标以及有真值时的性能指标，并分析误报、漏报和耗时。

没有独立真值时，可以证明覆盖增加、结构错误减少或复核工作量变化，不能证明准确率提高。仅修改文档格式或校验脚本不算新的识别运行，也不能报告模型性能提升。

针对失败样本回查得到的候选增加属于错误分析，不能当作未参与调参的泛化评估。初筛后选出的困难样本要注明选择偏差；由同一 Agent 再看也不是独立人工真值。如果执行 Agent 或模型标识不可固定，应称为针对性回归，而不是严格控制变量的 A/B 实验。

应保留一轮不知道基线结论的独立前向验证。若两个 Agent 对边界对象分歧，分歧本身是困难样本信号，不能用多数票伪造真值；把对象加入独立标注集，并把 `review` 作为可用的审慎输出状态。

新运行保存源图哈希、逐视角双类别检查与实际查看路径；详见 [evidence-workflow.md](evidence-workflow.md)。没有历史日志时，不能把基线细节覆盖率假设为 0%，只能写“未知、不可复核”。候选跨视角确认比例下降也可能来自更谨慎的实体对应规则，不应为追求 100% 确认而排除单视角阳性或硬合并。

## evaluation.md 建议内容

```text
输入：目录、物体数、图片数、不可读文件。
执行：Agent/模型可获得的标识、提示词/Skill版本、时间、检查方式。
覆盖：读取、初筛、细节复核各自的分子/分母与具体范围。
候选：两类候选数、区域簇或物理实体的计数口径、复核对象。
证据：跨视角佐证比例与分母、主要混淆项。
优化：baseline与本轮具体变化、复跑范围、指标变化、时间成本。
真值：来源及版本；无真值时明确未计算precision/recall/F1。
限制：未完成检查、遮挡、成像质量、结论可用范围。
```
