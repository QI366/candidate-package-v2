# 歧义驱动的复核与补拍

本参考用于候选存在竞争解释、视角对应不清或关键区域不可见时。目标是用最少的额外观察区分解释，而不是增加无目的的图片数量。以下方法是操作建议，当前数据尚未证明它们能提高识别性能。

## 先写歧义，再选择观察

对每个需要复核的候选，先写下至少两个可检验的解释，再确定哪种新观察最可能把它们区分开。没有办法区分时，保留 `review`，不要把建议中的观察结果当成既有证据。

| 歧义 | 需要观察的证据 | 建议的补充观察 |
|---|---|---|
| 线痕还是高光/阴影 | 物体表面是否存在稳定的沟槽、边缘或纹理中断；亮暗线是否随光源方向移动 | 固定物体方位，拍摄一张漫射光和一张斜向侧光照片；保持区域、焦距和曝光尽量一致 |
| 划痕还是正常加工纹 | 线条是否打断原有纹理、方向/间距是否规律，是否有局部材料变形 | 用近摄展示候选及周边完整表面；补充不同入射方向的侧光视图 |
| 材料缺损还是正常开口/遮挡 | 是否有不规则断边、断面或底材外露，边界是否属于规则设计结构 | 近摄边缘并同时包含周边结构；从略微不同的观察角度确认边界和底材关系 |
| 多张照片中的线痕是否为同一实体 | 可重复的结构锚点、物体角向方位与候选相对位置 | 对圆管等近旋转对称物体，在不遮挡检查区域的前提下贴可移除方位标记，记录每次转角并拍重叠视图 |

补拍请求应具体到物体、区域、视角/光照及其判别目的，例如：“拍套层缺口的斜下方近摄，画面同时包含套层边缘、露出的蓝色底材和相邻完整边缘，以确认是否存在真实断边。”避免仅要求“再拍清楚一点”。

## 分开记录光度与形貌

观察候选时分两栏记录，不把亮暗变化直接等同于表面形貌：

- **光度线索**：高光、阴影、颜色/亮度变化，以及它们在不同光照或方位下是否移动、变弱或消失。
- **形貌线索**：沟槽或隆起的边缘、轮廓中断、粗糙断面、缺失片块、底材外露，或基材纹理的实际中断。

光度线索可帮助定位，但仅有一条亮线或暗线不足以确认划痕或材料缺失。强形貌证据仍需检查是否为正常接缝、加工纹、孔洞或设计边界。数字增强、锐化、插值放大或生成式处理可用于导航，不得把处理产生的新纹理作为原图证据；最终判断应回到可追溯的原始像素。

## 按复核价值排序

优先处理满足以下任一条件的候选：不同 Agent 对类别/存在性意见相反；材料缺失会改变对象级结论；实体对应会改变计数；候选处于重要遮挡或只在低分辨率视角可见。为每项记录“当前歧义、所需观察、可区分的结果、若仍不清楚的处置”。不要只按模型置信标签排序，也不要在没有定义风险标准和真值时编造严重度分数。

现有样本中的 p10（套层边缘缺口意见不一致）、p25（旋转后线痕无法稳定对应）以及 p04/p30（黄铜表面线条与反光/加工纹混淆）可作为补拍方案的示例。静态输入无法补拍时，列出缺失观察并保持 `review`；不能推测补拍后的结果。

## 如何验证这项策略

将策略视为待验证假设。建议在按物体划分、与提示词开发隔离的验收集上，预先记录每个复核项及触发原因。由不看模型输出的标注者裁决原始歧义；若真实补拍，再盲评补拍前后结论。报告：

- 独立标注者对原始图像的分歧率，以及补拍后分歧率；同时报告样本数。
- `review` 项中，补拍后可形成有证据结论的比例（复核关闭率），并单列仍需复核的比例。
- 每个关闭项所需补拍张数、标注/复核人工耗时，以及两类缺陷各自的误报和漏报变化（只有独立真值时）。
- 未补拍项、不可拍项和选择补拍造成的样本偏差。

不能把 Agent 自身再次判断当成独立标注，也不能只在模型挑选的疑难项上报告性能提升。若没有独立真值或成对补拍数据，只记录方案和过程成本，不宣称分歧下降或识别性能改善。
